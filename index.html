PROJECTS

Joshlink Automobile

Joshlink Automobile is a responsive and user-friendly automobile marketplace website designed to showcase vehicle listings and connect buyers with sellers. The platform features dynamic car displays, inquiry functionality, content management integration, and a premium interface built with React, Tailwind CSS, Sanity, and Node.js.

LIVE DEMO

WonderKiddie Hub

WonderKiddie Hub is a responsive and user-friendly e-commerce website designed to sell children’s books through an engaging digital experience. The platform features product listings, shopping functionality, smooth navigation, and mobile-friendly layouts built with React, Tailwind CSS, and Node.js.

LIVE DEMO

Accessory Den

Accessory Den is a responsive and user-friendly
e-commerce shopping store designed to offer a fast and streamlined shopping experience.
The project features a prototype with a slideshow display, checkout, and cart pages,
all integrated into a user-friendly interface using HTML, CSS, and React.js..

LIVE DEMO

Air Aware

AirAware is a responsive and user-friendly
web application designed to provide real-time air quality information.
The project features a sleek interface with dynamic data fetching, interactive displays,
and accessibility-focused design, all built using React.js and Tailwind.

LIVE DEMO

Rent Ride

This car rental app is a responsive and user-friendly platform designed
to offer a seamless experience for users to rent any type of car in any location.
The project includes a fully interactive interface with a car selection process,
location-based filtering, and booking functionality, all built using React.

LIVE DEMO

Pokémon Fetcher

This web app allows you to explore Pokémon data by fetching information from the PokéAPI.
With a visually appealing card layout, you can search for Pokémon, view their details, and enjoy an interactive experience.
The app is built using HTML, CSS, and JavaScript to offer a responsive and engaging interface.

LIVE DEMO
